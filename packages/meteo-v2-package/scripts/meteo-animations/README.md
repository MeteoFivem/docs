# Meteo Animations

This is a guide about testing the Meteo V2 animation and emote script designed exclusively for the Meteo V2 package.

{% hint style="info" %}
Get access to our exclusive video testing guide on Discord to see all of this in action.
{% endhint %}

{% hint style="success" %}
Try it yourself for free on our showcase server. [See here to get access](../../how-to/how-to-access-showcase-server.md).
{% endhint %}

***

## Before You Start

* Access to the meteo showcase server
* Familiar with [getting started](../../getting-started.md) basics

***

## Testing Animations

* Use **F3** to open the animation menu
* Browse through emotes, dances, prop emotes, shared emotes, walking styles, expressions and animal emotes
* Use the search bar and arrow keys to quickly find and play emotes
* You can favorite emotes and add up to 8 emotes to your wheel for quick access
* Also you can use place position with emotes and place the emote so this will give more in roleplaying
* Use **B** to toggle pointing
* Use **X** to cancel current emote
* Use **X** (or `/handsup`) to put your hands up when you are not playing an emote
* Shared emotes work with nearby players too. the other player gets a request to accept or decline

### Chat Commands

* `/e emotename` or `/emote emotename` - play an emote
* `/emotecancel` - cancel current emote
* `/emotemenu` - open the animation menu
* `/walk style` - set your walking style
* `/mood expression` - set your expression
* `/nearby emotename` - request a shared emote with the nearest player
* `/pointing` - toggle finger pointing
* `/handsup` - toggle hands up

***

## Testing Per Character Saving

{% stepper %}
{% step %}
**Set your style**

Pick a walking style and an expression from the menu. also add a few emotes to your favorites and wheel
{% endstep %}

{% step %}
**Switch character**

Log out and load another character. you will see the walking style, expression, favorites and wheel are not carried over to this character
{% endstep %}

{% step %}
**Come back**

Load your first character again. your walking style, expression, favorites and wheel are restored for that character
{% endstep %}
{% endstepper %}
