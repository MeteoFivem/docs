# Meteo Pickpocket

This is a guide about testing the Meteo V2 pickpocket script designed exclusively for the Meteo V2 package. This is the easiest crime on the Meteo V2 package so far.

{% hint style="info" %}
Get access to our exclusive video testing guide on Discord to see all of this in action.
{% endhint %}

{% hint style="success" %}
Try it yourself for free on our showcase server. [See here to get access](../../how-to/how-to-access-showcase-server.md).
{% endhint %}

***

## Before You Start

* Access to the meteo showcase server
* Familiar with [getting started](../../getting-started.md) basics

***

## Testing Pickpocket

{% stepper %}
{% step %}
Go near any NPC ped with empty hands (unarmed), point target and click on pickpocket
{% endstep %}

{% step %}
Be ready for the keymash minigame from [meteo-minigames](../meteo-minigames/). Mash the shown key to fill the disc before it drains, finish it and get ped belongings lol
{% endstep %}

{% step %}
There are 4 reward tiers based on NPC wealth - poor (60% chance), middle (30%), rich (9%) and vip (1%)
{% endstep %}

{% step %}
Minigame gets harder with richer NPCs (more keys to mash, faster drain)
{% endstep %}
{% endstepper %}

> If you fail the NPC attacks you and there is a 60% chance police gets alerted

* You also drop a fingerprint at the scene (60% chance) unless wearing gloves
* 15 second cooldown between pickpockets

### Items You Can Get

* **poor NPCs** - meteo\_foldedcash ($10-50), tablet
* **middle NPCs** - meteo\_foldedcash ($50-150), tablet, fitbit, meteo\_hr\_oldkeys
* **rich NPCs** - meteo\_foldedcash ($150-400), goldchain, tablet, rolex
* **vip NPCs** - meteo\_foldedcash ($400-800), tenkgoldchain, rolex, diamond\_ring

### Cant Pickpocket

* Police, sheriff, security, military, prisoners, ambulance workers, other players, dead peds, peds in vehicles

### Selling Items

* You can sell stolen items at the pawnshop. Check out [meteo-pawnshop](../meteo-pawnshop/) testing guide for more info

***

## Good to Know

{% hint style="success" %}
Loot and odds for poor, middle class, rich and VIP marks, police alerts, fingerprint chance, stress and perk XP are all editable in-game from **Script Settings** in the admin menu ([meteo-manage](../meteo-manage/)) - no code editing needed, and your changes survive script updates.
{% endhint %}
