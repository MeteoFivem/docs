# Test Commands

{% hint style="warning" %}
These commands are only available on our showcase server. use them to quickly test gym features without grinding. They always act on yourself.
{% endhint %}

***

## Available Commands

### /gym \[action] \[stat] \[value]

All-in-one command for your gym stats.

#### View current stats

```
/gym info
```

Shows your strength, dexterity, endurance and energy in a notification.

#### Set a specific stat

```
/gym set strength 50
/gym set dexterity 80
/gym set endurance 30
```

Stats: `strength`, `dexterity`, `endurance`. Value is 0 to 100.

#### Set energy

```
/gym energy 100
```

#### Max all stats

```
/gym max
```

Sets every stat and your energy to the max.

#### Reset all stats

```
/gym reset
```

Sets every stat to 0 and fills your energy.
