# Meteo Loose Change

This is a guide about testing the Meteo V2 store robbery script designed exclusively for the Meteo V2 package.

{% hint style="info" %}
Get access to our exclusive video testing guide on Discord to see all of this in action.
{% endhint %}

{% hint style="success" %}
Try it yourself for free on our showcase server. [See here to get access](../../how-to/how-to-access-showcase-server.md).
{% endhint %}

{% hint style="warning" %}
Make sure to follow the [meteo-crimetablet](../meteo-crimetablet/) guide before following this.
{% endhint %}

***

## Before You Start

* Access to the meteo showcase server
* Familiar with [getting started](../../getting-started.md) basics

***

## Testing Loose Change

### Purchasing

{% stepper %}
{% step %}
Open tablet and go to services app. You can see the Loose Change service
{% endstep %}

{% step %}
If you do not have crypto use `/addcrypto 100` and get crypto

{% hint style="warning" %}
This is a testing command and only works on our showcase server
{% endhint %}
{% endstep %}

{% step %}
Purchase it (costs 25 MTC) and start
{% endstep %}

{% step %}
You can do this with a group too. Follow group guide on [crimetablet](../meteo-crimetablet/) guide and add group members too
{% endstep %}
{% endstepper %}

### Robbing the Store

{% stepper %}
{% step %}
After purchasing the loose change service you will get a notification and also marked store location. Also if you have a group they will see this too
{% endstep %}

{% step %}
Go to the location and take down the store owner (the shopkeeper is armed so be ready)
{% endstep %}

{% step %}
Loot the registers - you need to pass a lockpick skill check on each one
{% endstep %}

{% step %}
Also loot the shelves and grab spots around the store
{% endstep %}

{% step %}
Make sure to loot the NPC owner of the store body too. He has the best loot
{% endstep %}

{% step %}
Make sure to do this within the time frame (10 minutes) otherwise it will fail automatically and reset :)
{% endstep %}
{% endstepper %}

> Check out the testing video to understand it more visually and try it

### What You Can Get

* **from registers** - meteo\_foldedcash ($100-500), meteo\_reward\_box, meteo\_reward\_crate, diamond\_ring, rolex
* **from shelves** - meteo\_reward\_box, meteo\_reward\_crate, meteo\_foldedcash ($50-200), rolex, tablet, water\_bottle, coffee
* **from shopkeeper** - diamond\_ring, goldbar, rolex, diamond, meteo\_foldedcash ($50-200), meteo\_reward\_box, meteo\_reward\_crate, meteo\_datafile

***

## Good to Know

{% hint style="success" %}
Rewards, register loot, shelf loot, shopkeeper body loot, fingerprint chance, stress and perk XP are all editable in-game from **Script Settings** in the admin menu ([meteo-manage](../meteo-manage/)) - no code editing needed, and your changes survive script updates.
{% endhint %}
