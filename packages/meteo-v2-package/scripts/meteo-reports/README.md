# Meteo Report Menu

This is a guide about testing the Meteo V2 report script designed exclusively for the Meteo V2 package.

{% hint style="info" %}
Get access to our exclusive video testing guide on Discord to see all of this in action.
{% endhint %}

{% hint style="success" %}
Try it yourself for free on our showcase server. [See here to get access](../../how-to/how-to-access-showcase-server.md).
{% endhint %}

***

## Before You Start

* Access to the meteo showcase server
* Familiar with [getting started](../../getting-started.md) basics

***

## Testing Reports

{% stepper %}
{% step %}
You can open the report menu using `/report` or using f1 menu > general > report
{% endstep %}

{% step %}
The Home screen has quick actions to report a player, report a bug or ask a question, plus quick links to the server website, docs, Discord and store
{% endstep %}

{% step %}
Select a report type - there are player reports (RDM, VDM, metagaming, exploiting etc.), bug reports, suggestions and questions. Fill out the details, add optional evidence links and submit
{% endstep %}

{% step %}
Check My Reports to follow your reports and use the chat on a report to talk with staff
{% endstep %}
{% endstepper %}

### Testing as Admin

{% stepper %}
{% step %}
Admins automatically get access to the staff side of the menu. Access is given from the admin menu permissions
{% endstep %}

{% step %}
Open a report to see the details, then mark it as investigating, resolve it with resolution notes or archive it. Reports have priority levels (low, medium, high, urgent) based on category
{% endstep %}

{% step %}
Use teleport and bring on a report to go to the reporter or bring them to you, and reply to players from the Chats tab
{% endstep %}

{% step %}
Use the Players tab to search a player by State ID or name and see every report they filed and every report filed against them
{% endstep %}

{% step %}
Filter the reports list by status - pending, investigating, resolved
{% endstep %}
{% endstepper %}

### Report Categories

**Player reports:** RDM, VDM, metagaming, powergaming, fail RP, griefing, exploiting, harassment, other

**General reports:** bug report, suggestion, server issue, mapping issue, economy issue, job related, other

**Questions:** general question, rules clarification, jobs and economy, vehicles, properties, commands, technical support, other
