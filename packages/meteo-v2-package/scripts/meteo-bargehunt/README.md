# Meteo Barge Hunt

This is a guide about testing the Meteo V2 barge hunt script designed exclusively for the Meteo V2 package.

{% hint style="info" %}
Get access to our exclusive video testing guide on Discord to see all of this in action.
{% endhint %}

{% hint style="success" %}
Try it yourself for free on our showcase server. [See here to get access](../../how-to/how-to-access-showcase-server.md).
{% endhint %}

{% hint style="warning" %}
Make sure to follow the [meteo-crimetablet](../meteo-crimetablet/) guide before following this.
{% endhint %}

***

## Before You Start

* Access to the meteo showcase server
* Familiar with [getting started](../../getting-started.md) basics

***

## Testing Barge Hunt

### Requirements

{% hint style="warning" %}
Make sure to follow the [meteo-organizations](../meteo-organizations/) testing guide and join an org or create one to do this. Since this needs organization level 2
{% endhint %}

{% hint style="warning" %}
Use `/setorglevel xp 1000` to get org to level 2. This command only works on our showcase server. For more info check [meteo-organizations test-commands](../meteo-organizations/test-commands.md)
{% endhint %}

{% hint style="warning" %}
If you do not have crypto use `/addcrypto 400` (admin command) and get crypto
{% endhint %}

### Starting the Hunt

{% stepper %}
{% step %}
#### Purchase the Service

Open tablet and go to services app. You can see the Barge Hunt service. Purchase it (costs 275 MTC) and start
{% endstep %}

{% step %}
#### Add Group Members (Optional)

You can do this with a group too. Follow group guide on [crimetablet](../meteo-crimetablet/) guide and add group members too
{% endstep %}
{% endstepper %}

### Doing the Hunt

{% stepper %}
{% step %}
#### Go to Location

After purchasing if you have group they will get location marked on map. Go to that location. You might need a boat to get closer
{% endstep %}

{% step %}
#### Clear Guards

Kill the guards and loot them. Police can get alerted on [meteo-mdt](../meteo-mdt/) when you enter the zone and when you search crates
{% endstep %}

{% step %}
#### Loot Boxes

Also find hunt boxes and loot them too. You will get items like `meteo_bargehunt_cargo`, `meteo_bargehunt_contraband`, reward boxes, meteo\_foldedcash and more. Use the cargo and contraband crates and see your luck :)
{% endstep %}

{% step %}
#### Escape

After all boxes and guards looted it will give countdown and escape before that countdown runs out and complete
{% endstep %}
{% endstepper %}

***

## Good to Know

{% hint style="success" %}
Rewards, crate loot, guard loot, escape time, fingerprint chance, stress and perk XP are all editable in-game from **Script Settings** in the admin menu ([meteo-manage](../meteo-manage/)) - no code editing needed, and your changes survive script updates. Add or edit barges in-game with the Barge Locations creator - place the barge on the water first, then aim at its deck to drop each crate and guard.
{% endhint %}

> Connected with [meteo-perks](../meteo-perks/). Barge hunts give XP on the **Barge Hunt** perk line

> meteo\_foldedcash you loot can be washed into clean cash through the [hustling job](../meteo-hussling/)
