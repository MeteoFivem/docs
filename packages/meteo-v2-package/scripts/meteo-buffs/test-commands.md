# Test Commands

{% hint style="warning" %}
These commands are only available on our showcase server. use them to quickly test item effects and cravings without grinding.
{% endhint %}

***

## Available Commands

### /buffs use \[item]

Runs an item's effects without holding or using the item.

```
/buffs use beer
/buffs use steroids
```

### /buffs crave \[craving]

Hooks you on a craving instantly. The craving starts on the next tick.

```
/buffs crave alcohol
/buffs crave cocaine
```

Cravings: `fast_food`, `junk_food`, `alcohol`, `weed`, `cocaine`, `meth`, `ecstasy`, `oxy`, `steroids`

### /buffs clear

Clears every running effect and craving.

```
/buffs clear
```

### /buffs item \[item]

Prints how an item is set up (use type, hunger, thirst, effects, craving) to the server console.

```
/buffs item joint
```

### /buffs list

Shows how many items and cravings are set up.

```
/buffs list
```

***

## Player Command

### /charstatus

Opens a quick character status list with your health, running effects with the time left and your cravings. Available for every player and can be bound to a key in GTA key bindings. The same info is in the inventory **Status** tab.

```
/charstatus
```
