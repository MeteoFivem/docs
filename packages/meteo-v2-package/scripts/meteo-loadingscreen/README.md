# Meteo Loading Screen

Custom loading screen designed exclusively for the Meteo V2 package.

{% hint style="info" %}
Get access to our exclusive video testing guide on Discord to see all of this in action.
{% endhint %}

{% hint style="success" %}
Try it yourself for free on our showcase server. [See here to get access](../../how-to/how-to-access-showcase-server.md).
{% endhint %}

***

## Features

* Custom branded loading screen with server name, version and max players
* Background video with a poster image while it loads
* Background music player with a now playing panel
* Rotating tips, server team list and social media links
* Fully translated to the server language

{% hint style="success" %}
Server team, social links, music playlist, background video and tips are all configurable on our config. You can change them once you get the package. We will guide you :)
{% endhint %}
