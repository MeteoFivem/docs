# Meteo Forest Hunt

This is a guide about testing the Meteo V2 forest hunt script designed exclusively for the Meteo V2 package.

{% hint style="info" %}
Get access to our exclusive video testing guide on Discord to see all of this in action.
{% endhint %}

{% hint style="success" %}
Try it yourself for free on our showcase server. [See here to get access](../../how-to/how-to-access-showcase-server.md).
{% endhint %}

{% hint style="warning" %}
Make sure to follow the [meteo-crimetablet](../meteo-crimetablet/) guide before following this.
{% endhint %}

***

## Before You Start

* Access to the meteo showcase server
* Familiar with [getting started](../../getting-started.md) basics

***

## Testing Forest Hunt

### Requirements

{% hint style="warning" %}
Make sure to follow the [meteo-organizations](../meteo-organizations/) testing guide and join an org or create one to do this. Since this needs organization level 2
{% endhint %}

{% hint style="warning" %}
Use `/setorglevel xp 1000` to get org to level 2. This command only works on our showcase server. Check [meteo-organizations test-commands](../meteo-organizations/test-commands.md) for more info
{% endhint %}

{% hint style="warning" %}
If you do not have crypto use `/addcrypto 300` (admin command) and get crypto
{% endhint %}

### Starting the Hunt

{% stepper %}
{% step %}
#### Purchase the Service

Open tablet and go to services app. You can see the Forest Hunt service and purchase it (costs 225 MTC)
{% endstep %}

{% step %}
#### Add Group Members (Optional)

You can do this with a group too. Follow group guide on [crimetablet](../meteo-crimetablet/) guide and add group members too
{% endstep %}
{% endstepper %}

### Doing the Hunt

{% stepper %}
{% step %}
#### Go to Camp

After purchasing go to the marked forest camp location on the map. Group members can see this too
{% endstep %}

{% step %}
#### Clear Guards

The camp is guarded so come prepared with weapons and armor. Each camp has its own guards and crates (the first camp has 12 guards and 4 crates, the bigger camps have more). Kill the guards and search the loot crates in the camp (5 second search animation per crate)
{% endstep %}

{% step %}
#### Watch for Police

There is a 30% chance police gets dispatched on [meteo-mdt](../meteo-mdt/) per search so be careful
{% endstep %}

{% step %}
#### Collect Loot

You will get items like `meteo_foresthunt_supplies`, `meteo_foresthunt_contraband` and also reward boxes, meteo\_foldedcash, crafting materials and more. Folded cash can be washed into clean cash through the [hustling job](../meteo-hussling/). Use the supplies and contraband items and see your luck :) check out [meteo-rewards](../meteo-rewards/) testing guide for more info about opening crates
{% endstep %}

{% step %}
#### Complete Within Time

Make sure to complete within the 30 minute time limit
{% endstep %}
{% endstepper %}

***

## Good to Know

{% hint style="success" %}
Rewards, loot table, fingerprint chance, stress and perk XP are all editable in-game from **Script Settings** in the admin menu ([meteo-manage](../meteo-manage/)) - no code editing needed, and your changes survive script updates. Add or edit camps in-game with the Forest Camps creator - place the centre, the crates and the guards, and the next hunt uses them.
{% endhint %}

> Connected with [meteo-perks](../meteo-perks/). Forest hunts give XP on the **Forest Hunt** perk line
